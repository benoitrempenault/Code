Studio Kadima — se connecter

Mode d'emploi · conseillers · octobre 2026
Plus de mot de passe. Vous entrez avec votre e-mail century21.fr : un lien de connexion arrive dans votre boîte, puis un code par SMS la première fois sur un nouvel appareil. Ensuite l'appareil reste connecté 90 jours.

Se connecter sur un ordinateur ou un téléphone

1
Ouvrez studio.century21-kadima.fr/mandat-pro/compte.html
2
Saisissez votre adresse e-mail century21.fr et cliquez Recevoir mon lien de connexion.
3
Ouvrez l'e-mail « Votre lien de connexion Studio » sur le même appareil et cliquez le lien, puis Ouvrir ma session. Le lien est valable 15 minutes et ne sert qu'une fois.
4
Un code à 6 chiffres arrive par SMS sur votre mobile : tapez-le, puis Valider le code. C'est fini, vous êtes connecté pour 90 jours sur cet appareil.
Pas de réseau pour le SMS ? Cliquez Recevoir le code par e-mail : le code arrive dans votre boîte.

Sur le téléphone, depuis l'app de l'écran d'accueil

Le lien de l'e-mail s'ouvre dans Safari ou Chrome, pas dans l'app. Dans ce cas : dans l'e-mail, restez appuyé sur le lien → Copier, ouvrez l'app, puis collez le lien dans le champ « collez ici le lien de connexion reçu ». Le code SMS est ensuite demandé normalement.

Si vous aviez un raccourci « Studio » sur l'écran d'accueil, refaites-le depuis la nouvelle adresse studio.century21-kadima.fr.

Chaque appareil a sa connexion

  • Ordinateur, téléphone, tablette : un lien et un code par appareil. Cliquer le lien sur le téléphone connecte le téléphone, pas l'ordinateur.
  • À chaque nouvelle connexion, vous recevez un e-mail « Nouvelle connexion sur votre compte Studio ». Si ce n'est pas vous, ouvrez Mon compte → Mes appareils et fermez l'appareil inconnu, ou cliquez Déconnecter tous mes appareils.
  • Poste partagé : pensez à Changer de compte (se déconnecter) sur Mon compte avant de laisser la place.

Mon compte

  • Mes appareils : la liste de vos sessions ouvertes, avec un bouton Fermer pour chacune.
  • Mon mobile : le numéro qui reçoit le code. Changé de téléphone ? Saisissez le nouveau numéro, il sera vérifié par le prochain code.
  • Ouvrir mes outils ramène à l'accueil Studio (fiches, brochures, parcours R1/R2, suivi, permanence…).

Ça ne marche pas ?

  • « Lien invalide ou expiré » : le lien a plus de 15 minutes ou a déjà servi. Redemandez-en un.
  • « Code incorrect » : vérifiez le dernier SMS reçu ; après 5 essais, redemandez un code.
  • Pas d'e-mail reçu : regardez les indésirables, puis demandez à Benoît de vérifier que votre adresse est bien celle de votre profil.
