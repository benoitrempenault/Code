Studio Kadima — se connecter

Mode d'emploi · conseillers · octobre 2026
Plus de mot de passe. Vous entrez avec votre e-mail century21.fr : un lien de connexion arrive dans votre boîte, puis un code par SMS la première fois sur un nouvel appareil. Ensuite l'appareil reste connecté 90 jours.

Où est Studio ?

À l'adresse studio.century21-kadima.fr/mandat/ : mettez-la en favori ou en raccourci sur l'écran d'accueil. Connecté, vous entrez directement ; sinon la page de connexion s'ouvre. Le bouton « Accès collaborateurs » du site n'existe plus.

Se connecter (une fois par appareil)

1
Sur la page de connexion (studio.century21-kadima.fr/mandat-pro/compte.html), vérifiez que vous êtes bien dans Safari, Chrome ou votre raccourci Studio.
2
Saisissez votre adresse e-mail century21.fr et cliquez Recevoir mon lien de connexion.
3
Laissez cette page ouverte. Ouvrez l'e-mail « Votre lien de connexion Studio » et cliquez le lien, puis Ouvrir ma session : peu importe où le lien s'ouvre (application mail, autre onglet), la page Studio laissée ouverte se connecte toute seule. Le lien est valable 15 minutes et ne sert qu'une fois.
4
Sur la page Studio, un code à 6 chiffres arrive par SMS sur votre mobile : tapez-le, puis Valider le code. C'est fini, vous êtes connecté pour 90 jours sur cet appareil.
Pas de réseau pour le SMS ? Cliquez Recevoir le code par e-mail : le code arrive dans votre boîte.

Sur le téléphone

Demandez le lien depuis Studio (Safari, Chrome ou le raccourci de l'écran d'accueil), puis revenez dans Studio après avoir cliqué le lien dans l'e-mail : la page se connecte toute seule et demande le code. Si vous avez fermé la page entre-temps, collez le lien dans le champ « collez ici le lien de connexion reçu » (dans l'e-mail : rester appuyé sur le lien → Copier).

Faites votre raccourci d'écran d'accueil une fois connecté, depuis studio.century21-kadima.fr/mandat/ (pas depuis un e-mail ni depuis le site) : il s'ouvrira directement sur vos outils, reconnus 90 jours.

Chaque appareil a sa connexion

  • Ordinateur, téléphone, tablette : un lien et un code par appareil. C'est l'appareil où vous avez demandé le lien qui se connecte.
  • À chaque nouvelle connexion, vous recevez un e-mail « Nouvelle connexion sur votre compte Studio ». Si ce n'est pas vous, ouvrez Mon compte → Mes appareils et fermez l'appareil inconnu, ou cliquez Déconnecter tous mes appareils.
  • Poste partagé : pensez à Changer de compte (se déconnecter) sur Mon compte avant de laisser la place.

Mon compte

  • Mes appareils : la liste de vos sessions ouvertes, avec un bouton Fermer pour chacune.
  • Mon mobile : le numéro qui reçoit le code. Changé de téléphone ? Saisissez le nouveau numéro, il sera vérifié par le prochain code.
  • Ouvrir mes outils ramène à l'accueil Studio (fiches, brochures, parcours R1/R2, suivi, permanence…).

Ça ne marche pas ?

  • « Lien invalide ou expiré » : le lien a plus de 15 minutes ou a déjà servi. Redemandez-en un.
  • « Code incorrect » : vérifiez le dernier SMS reçu ; après 5 essais, redemandez un code.
  • Pas d'e-mail reçu : regardez les indésirables, puis demandez à Benoît de vérifier que votre adresse est bien celle de votre profil.
