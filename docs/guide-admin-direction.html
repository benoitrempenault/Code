Studio Kadima — administrateur & direction

Mode d'emploi · octobre 2026
Depuis le 12 octobre : plus de compte partagé ni de mot de passe. Chaque personne entre avec son e-mail (lien puis code SMS sur un nouvel appareil), et toute l'équipe se gère dans un seul endroit : Administration → Réglages → L'équipe, sur studio.century21-kadima.fr/administration/

Les entrées

  • studio.century21-kadima.fr/mandat/ : l'accueil des outils, l'adresse à mettre en favori et en raccourci (une fois connecté).
  • Le bouton Accès collaborateurs en bas du site century21-kadima.fr mène à la même adresse. L'ancienne porte à code partagé est fermée : plus de code à distribuer ni à révoquer.
  • Les anciennes adresses github.io redirigent d'elles-mêmes.

Les deux rôles

  • Direction (case « Direction » sur le profil) : voit tous les parcours R1/R2 de l'agence, pas seulement les siens. Rien d'autre ne change.
  • Administration (case « Administration ») : ouvre la page Administration — contacts, imports, anniversaires, acheteurs, estimations, offres, bilans, réglages, et l'équipe. À réserver à quelques personnes.

L'équipe : une ligne par personne

Chaque ligne montre le profil (photo, fonction, téléphone, e-mail) et, dans la colonne Accès, l'état du compte avec trois cases :

  • Actif : la personne entre dans Studio et apparaît dans les listes. Décochez-la au départ d'un collaborateur : ses sessions sont fermées immédiatement et plus aucun lien de connexion ne lui part.
  • Direction et Administration : voir ci-dessus. Vous ne pouvez pas retirer votre propre case Administration.

Sous les cases : « 2 appareils connectés · 📱 06 ** ** ** 21 » dit si la personne s'est connectée et sur quel mobile part son code, avec les boutons ✉ Lien, 📱 Mobile, ⏏ Déconnecter et 🗑 Retirer.

1
➕ Créer l'accès : crée le compte de la personne et lui envoie son lien de bienvenue (valable 7 jours). Il faut un e-mail sur son profil.
2
✉ Lien : lui renvoie un lien de connexion (lien perdu, nouvel appareil, boîte mal reçue).
3
🗑 Retirer : départ définitif. Le profil disparaît des listes et des guides, le compte et ses sessions sont supprimés. Ses fiches, parcours et dossiers restent dans l'agence. Pour un départ temporaire, préférez décocher Actif.
4
⟳ Importer depuis le site : reprend les conseillers de century21-kadima.fr (photo, fonction, téléphone) et crée tout seul le compte de ceux qui ont une adresse century21.fr. Les autres domaines se créent avec « Créer l'accès ».
La ligne « 25 / 30 sièges utilisés » sous la liste : quand il n'y a plus de siège, la création s'arrête. Les sièges se relèvent dans la console Studio (studio.century21-kadima.fr/admin.html, clé ADMIN_KEY), ligne CENTURY 21 Kadima.

Le code SMS et le mobile

  • Le code part sur le mobile du profil conseiller (téléphone en 06/07). Sans mobile, le lien e-mail suffit.
  • Téléphone changé : la personne saisit son nouveau numéro sur Mon compte → Mon mobile, ou vous le posez pour elle avec le bouton 📱 Mobile de sa ligne ; il est vérifié par le prochain code.
  • Code non reçu : la personne clique Recevoir le code par e-mail sur l'écran du code.

Surveiller

  • 📜 Journal des connexions (bouton au-dessus de la liste) : qui s'est connecté, quand, depuis quel appareil et quelle adresse IP ; codes refusés ; appareils fermés.
  • Chaque personne reçoit un e-mail « Nouvelle connexion sur votre compte Studio » à chaque ouverture de session, avec le lien pour fermer un appareil inconnu.
  • Vous recevez un e-mail si les envois automatiques (vœux, relances, bilans) atteignent le plafond du jour ou sont refusés par Brevo.

Cas pratiques

  • Nouveau conseiller : ajoutez-le sur le site century21-kadima.fr, puis « Importer depuis le site » ; sinon « + Ajouter un conseiller » avec son e-mail, puis « Créer l'accès ». Envoyez-lui le mode d'emploi « se connecter ».
  • Départ : décochez Actif le jour même, puis « Retirer » quand le dossier est clos.
  • Téléphone perdu : bouton ⏏ Déconnecter de sa ligne (toutes ses sessions tombent, le compte reste), puis 📱 Mobile si le numéro change ; la personne se reconnecte avec un nouveau lien et un code.
  • Donner la direction à quelqu'un : cochez Direction ; effet immédiat, sans reconnexion.
