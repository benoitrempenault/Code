⚠️ Rituel d'ouverture — À FAIRE DANS CHAQUE NOUVELLE FENÊTRE PowerShell (les variables meurent avec la fenêtre ; sans ça : « Clé admin invalide » ou « référence d'objet non définie ») :
$k = Read-Host "Collez votre ADMIN_KEY"
$env:CLOUDFLARE_API_TOKEN = Read-Host "Collez votre jeton Cloudflare"   # seulement si commandes wrangler
Les deux valeurs sont dans le gestionnaire de mots de passe. `$k` sert aux commandes Invoke-RestMethod ; le jeton Cloudflare aux commandes wrangler (dans le dossier server du dernier ZIP).

👤 Créer un conseiller Kadima (30 sièges)

Invoke-RestMethod -Method Post -Uri "https://studio-brochure-api.studiobrochure.workers.dev/admin/users" `
  -Headers @{ "X-Admin-Key" = $k } -ContentType "application/json; charset=utf-8" `
  -Body (@{ agency_id = "ag_8csricwct9"; email = "prenom.nom@century21.fr"; name = "Prenom Nom" } | ConvertTo-Json)
Puis envoyer le kit PDF au conseiller (mémo + mode d'emploi + dépannage). ag_8csricwct9 = Century 21 Kadima.

🏢 Créer une agence CLIENTE (essai 14 jours)

Invoke-RestMethod -Method Post -Uri "https://studio-brochure-api.studiobrochure.workers.dev/admin/agencies" `
  -Headers @{ "X-Admin-Key" = $k } -ContentType "application/json; charset=utf-8" `
  -Body (@{ name = "Nom Agence"; email = "contact@agence.fr"; user_name = "Prenom Nom" } | ConvertTo-Json) | ConvertTo-Json -Depth 5
→ envoyer le welcome_link reçu (valable 7 jours, lien vers studiobrochure.fr/app). Ajouter status = "active" dans le Body pour une agence déjà abonnée. Noter l'id (ag_…).

📋 Lister les agences (id, statut, usage du mois)

Invoke-RestMethod -Uri "https://studio-brochure-api.studiobrochure.workers.dev/admin/agencies" `
  -Headers @{ "X-Admin-Key" = $k } | ConvertTo-Json -Depth 5

✏️ Modifier une agence (sièges, quota IA, nom)

Invoke-RestMethod -Method Post -Uri "https://studio-brochure-api.studiobrochure.workers.dev/admin/agencies/AG_ID_ICI" `
  -Headers @{ "X-Admin-Key" = $k } -ContentType "application/json" -Body '{"seats": 10, "quota_eur": 40}'
Champs au choix : seats, quota_eur, name, app_base. L'ID (ag_…) se place dans l'ADRESSE, entre agencies/ et la fin.

⛔ Suspendre / réactiver une agence (fin d'abonnement, impayé)

Invoke-RestMethod -Method Post -Uri "https://studio-brochure-api.studiobrochure.workers.dev/admin/agencies/AG_ID_ICI/status" `
  -Headers @{ "X-Admin-Key" = $k } -ContentType "application/json" -Body '{"status":"suspended"}'
Réactiver : remplacer par "active". Effet immédiat : IA coupée, écriture de fiches bloquée (lecture conservée). « Agence introuvable » = mauvais ag_… → relister.
