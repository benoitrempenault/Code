🛠️ Commandes wrangler utiles (dossier server, jeton posé)

Promouvoir un compte en admin d'agence (fait apparaître « Mes conseillers ») :
wrangler d1 execute studio-brochure --remote --command "UPDATE users SET role='admin' WHERE email='prenom.nom@century21.fr'"
Débloquer quelqu'un (sinon la console web le fait aussi) :
wrangler d1 execute studio-brochure --remote --command "DELETE FROM login_tokens WHERE user_id = (SELECT id FROM users WHERE email = 'son.email@exemple.fr')"
Vérifier un rôle / un compte (lecture seule) :
wrangler d1 execute studio-brochure --remote --command "SELECT email, role FROM users WHERE email='prenom.nom@century21.fr'"

🤖 Modèles IA (coût maîtrisé)

Par défaut, la rédaction de brochure et la transcription de notes manuscrites tournent sur Claude Opus (qualité) ; le reste (quartier, annonce, légendes, extraction DPE/surfaces, fiche) sur Sonnet (~5× moins cher). Le sélecteur de l'app « Tout en Opus » force le maximum partout si besoin.

💾 Sauvegarde de la base (automatique)

Workflow « Sauvegarde D1 (chiffrée) » : tous les jours à 03:00 UTC (+ manuel via Actions → Run workflow), export chiffré AES-256 conservé 90 j comme artefact. Secrets à poser une fois (Settings → Secrets and variables → Actions) : CLOUDFLARE_API_TOKEN (accès D1) et BACKUP_PASSPHRASE (phrase de chiffrement — à garder au coffre, sans elle rien n'est lisible).
Restaurer : Actions → run → télécharger l'artefact d1-backup-… → déchiffrer puis réimporter :
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in d1-dump.sql.enc -out d1-dump.sql -pass pass:VOTRE_PHRASE
wrangler d1 execute studio-brochure --remote --file d1-dump.sql
Conseil : télécharger une sauvegarde sur un disque hors-ligne de temps en temps (les artefacts expirent à 90 j).
