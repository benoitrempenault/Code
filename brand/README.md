# Charte — logo « Studio Brochure »

Logo **« Le pli »** : trois panneaux (une brochure qui se déplie), dont un doré.

## Fichiers

| Fichier | Usage |
|---------|-------|
| `logo-horizontal.svg` / `.png` | Logo complet (symbole + nom) sur fond clair. **PNG = pour le dépôt INPI et l'e-mail.** |
| `logo-horizontal-blanc.svg` | Logo complet sur fond sombre. |
| `logo-mono-noir.svg` | Version 1 couleur (impression, tampon). |
| `symbole.svg` / `.png` | Le symbole seul (icône d'app, avatar, filigrane). |
| `symbole-blanc.svg` | Symbole seul sur fond sombre. |
| `favicon.svg` | Icône d'onglet du navigateur (déjà en place sur toutes les pages). |

## Couleurs

- Encre : `#1a1714` — Or : `#b58a4a` (foncé) / `#c2a36b` (clair sur fond sombre) — Papier : `#f2ead9`

## Typographie

- Nom du logo : **Fraunces** (serif). « Studio » en 500, « Brochure » en 600.
- Les SVG référencent Fraunces ; les **PNG** l'ont déjà « aplatie » (police incluse) — utilisez les
  PNG partout où la police n'est pas garantie (e-mail, dépôt INPI, impression).

## Zone de protection & taille mini

- Laissez autour du logo une marge d'au moins la largeur du panneau doré.
- Taille minimale conseillée : 120 px de large (logo complet), 24 px (symbole seul).

## Dépôt de marque

Joindre `logo-horizontal.png` (haute résolution) au dépôt INPI **semi-figuratif**. Voir
`../docs/marque-studio-brochure.md`.
